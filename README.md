A cybersecurity multitool containing some usefull tools such as NMap, NSLookup, WireShark and our custom "StarStrike"

Star Strike is made by my colleague Solez

Looking for a cybersecurity multitool? You just found one. It is still a work in progress, but more tools are comming later on.

MALICIOUS USE OF THIS TOOL IS ILLEGAL AND CAN LEAD TO JAIL TIME, READ #README FOR MORE INFO

CURENTLY WE SUPPORT WINDOWS 10/11 AND LINUX 
MACOS SUPPORT MAY COME LATER ON. TERMUX SUPPORT ISN'T PLANNED YET

For Linux, use "Launcher.sh" 

FOR IT TO RUN ON LINUX:
1) git clone https://github.com/MikyIsDaBest/StarBreak

2) cd StarBreak

3) chmod +x Launcher.sh   - this makes the launcher executable

4) ./Launcher.sh         - Star Strike requires root access

5) sudo ./Launcher.sh    -command for root access
